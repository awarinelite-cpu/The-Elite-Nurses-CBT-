# THE ELITES NURSES

A SvelteKit starter for a nursing examination preparation platform.

## Included in this first build

- Public landing page and brand system
- Student dashboard
- Reading Mode subject browser
- Exam Mode selection and exam setup screen
- Login screen UI
- Admin overview UI
- Responsive layouts for desktop, tablet and mobile
- Firebase client initialisation (environment-variable based)
- Vercel adapter configuration

**Important:** The current screens use demonstration data. Authentication, Firestore question loading, secure exam delivery/scoring, Cloudinary uploads and Paystack payments still need to be connected before production use.

## Run locally

1. Install Node.js (current LTS).
2. Extract this project.
3. In the project folder run:

   ```bash
   npm install
   cp .env.example .env
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Connect Firebase

1. Create a Firebase project at https://console.firebase.google.com/.
2. Add a Web App in Project Settings.
3. Enable Authentication (Email/Password to begin with).
4. Create a Cloud Firestore database.
5. Copy the web app configuration values into `.env`.
6. Add Firestore Security Rules before adding real student or exam data.

Never place a Firebase Admin SDK private key or Paystack secret key in a `PUBLIC_` environment variable.

## Connect Cloudinary

1. Create a Cloudinary account.
2. Create an upload preset.
3. For production, prefer signed uploads generated by a trusted server endpoint. An unsigned preset is easier for early testing but must be restricted by file type, size and allowed transformations.
4. Save the cloud name and upload preset in `.env` if using unsigned test uploads.

Store image URLs and Cloudinary public IDs in Firestore; store the image files themselves in Cloudinary.

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. Import the repository in https://vercel.com/.
3. Vercel should detect SvelteKit automatically.
4. Add the same environment variables in Vercel Project Settings.
5. Deploy.

- `questions`
- `exams`
- `examAttempts`
- `bookmarks`
- `studyProgress`
- `subscriptions`
- `payments`
- `auditLogs`

For CBT integrity, do not expose correct answers to the browser during an active exam. Keep scoring and payment verification on trusted server-side code (for example, Firebase Cloud Functions). Verify Paystack transactions server-side and process signed webhooks before granting premium access.

## Content quality

Keep verified past questions clearly distinguished from reconstructed questions and original mock questions. Confirm rights to publish question content and have clinical content reviewed by a qualified nursing educator.
